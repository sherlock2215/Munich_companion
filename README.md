# MunichCompanion

MunichCompanion is a web application developed during HackaTUM 2025 that
helps newcomers in Munich connect with others, navigate the city, and
feel welcomed from day one.

## 🚀 Features

-   **Personalized onboarding** for international students and expats.
-   **Event recommendations** based on user interests.
-   **Interactive chatbot** for city guidance.
-   **Social connection matching** to combat isolation.

## 🛠️ Tech Stack

  Component        Technology
  ---------------- ---------------------
  Frontend         Next.js / React
  Backend          Python (FastAPI)
  Database         PostgreSQL / SQLite
  Authentication   NextAuth / JWT
  Styling          Tailwind CSS

## 🔧 Installation

``` bash
# Clone the repository
git clone https://github.com/sherlock2215/Munich_companion
cd Munich_companion

# Install backend dependencies
pip install -r requirements.txt

# Install frontend dependencies
npm install
```

## ▶️ Usage

``` bash
# Start backend
uvicorn main:app --reload

# Start frontend
npm run dev
```

Then open the application at `http://localhost:3000`.
